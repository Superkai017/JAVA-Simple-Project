## 📝 Description

This repository contains a set of exercises and small Java programs completed collaboratively as part of our coursework/practice. Each exercise focuses on strengthening fundamental Java programming skills such as string manipulation, control flow, and object-oriented basics.

## 🚀 Getting Started

### Prerequisites
- Java JDK installed (JDK 8 or higher recommended)

### Running the programs
```bash
# Compile
javac FileName.java

# Run
java FileName
```
